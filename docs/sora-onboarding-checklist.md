## Deskripsi
Urutan langkah yang direkomendasikan saat pertama kali mengatur data operasional toko di Sora Seventh, mencakup pengaturan profil bisnis hingga mulai menerima transaksi kasir.

## Urutan Langkah
1. **Pengaturan → Profil Bisnis → Profil Usaha** — atur jam operasional usaha agar pelanggan tahu jam buka/tutup.
2. **Pengaturan → Metode Pembayaran → Buat Metode Pembayaran** — buat dan atur opsi pembayaran yang digunakan toko.
3. **Pengaturan → Regulasi → Buat Regulasi** — atur biaya tambahan/regulasi usaha.
4. **Pengaturan → Nota → Atur Tampilan Nota** — atur tampilan struk toko.
5. **Tagihan → Tambah Meja → Atur Meja** — atur layout dan nomor meja.
6. **Bahan Baku → Buat Satuan Bahan → Buat Satuan Bahan Baku** — tulis satuan ukur bahan baku agar takaran resep valid.
7. **Bahan Baku → Buat Bahan Baku → Buat Bahan Baku** — daftarkan semua bahan baku yang dibutuhkan untuk resep menu.
8. **Resep → Kategori Menu → Buat Kategori Menu** — buat kategori menu agar pelanggan mudah mencari.
9. **Resep → Buat Menu Baru** — buat menu lengkap dengan detail resep.
10. **Resep → Buat Varian Menu** — tambahkan varian rasa/topping pada menu.
11. **Resep → Buat Kemasan** — atur packaging produk, khusus untuk pesanan take away.
12. **Resep → Buat Online Food** — aktifkan dan atur layanan online food.
13. **Kasir → Kas Kecil → Mulai Sesi Kasir** — klik untuk mulai menerima transaksi.
14. **Kasir → Kas Kecil → Tutup Kasir** — klik untuk mengakhiri transaksi hari itu.

## Catatan Penting
Urutan ini direkomendasikan karena beberapa data saling bergantung — misalnya satuan bahan baku harus dibuat sebelum input bahan baku, dan bahan baku harus ada sebelum membuat resep menu.
